# 术语表 (Glossary)

## 架构与数据

| 术语 | 英文 | 定义 |
|------|------|------|
| **本地优先** | Local-First | 所有数据操作优先在本地设备完成，网络仅用于同步。用户在网络不可用时仍可完整使用应用。 |
| **CRDT** | Conflict-free Replicated Data Type | 无冲突复制数据类型。一种可以在多个设备上独立并发编辑，合并后自动保持一致的数据结构。 |
| **Automerge** | — | 一个成熟的 CRDT 库（JavaScript/TypeScript），是本项目的数据层核心技术。 |
| **文档** | Document | CRDT 中的核心数据单元。在本项目中，所有 Todo 数据存储在一个 CRDT 文档中。 |
| **合并** | Merge | 将两个或多个设备上的 CRDT 文档变更合并为一个一致的版本。Automerge 自动处理此过程。 |
| **操作日志** | OpLog / Append-Only Log | CRDT 内部维护的增量变更日志。每次修改追加一条记录，这是实现无冲突合并的基础。 |
| **因果序** | Causal Ordering | CRDT 使用向量时钟追踪事件发生的因果顺序，确保合并时不会丢失信息。 |

## 平台

| 术语 | 英文 | 定义 |
|------|------|------|
| **Electron** | — | 当前 macOS 桌面端的运行时框架。将 Vue 3 Web 应用打包为原生桌面应用。 |
| **Capacitor** | — | 将 Web 应用打包为 iOS/Android 原生应用的框架。由 Ionic 团队维护。 |
| **WebView** | — | 移动端应用中用于渲染 Web 内容的原生组件。Capacitor 应用本质上是一个全屏 WebView。 |
| **iCloud Drive** | — | Apple 的云存储服务，用于 macOS/iOS 设备间文件同步。 |
| **Google Drive** | — | Google 的云存储服务，用于 Android 设备文件同步。 |
| **WebDAV** | — | 一种基于 HTTP 的文件管理协议，支持用户自建或使用第三方（如 Nutstore/坚果云）服务。 |

## 应用功能

| 术语 | 英文 | 定义 |
|------|------|------|
| **四象限** | Eisenhower Matrix | 根据重要性和紧急性将任务分为四个象限的管理方法：重要且紧急、重要不紧急、紧急不重要、不重要不紧急。 |
| **日历视图** | Calendar View | 在日历上按日期展示任务的可视化视图，支持月/周/日三种粒度。 |
| **清单** | List / Project | 任务的分类集合。类似文件夹，一个清单包含多个任务。 |
| **标签** | Tag | 用于对任务进行多维度分类的标记。一个任务可以有多个标签。 |
| **全天任务** | All-Day Task | 没有具体时间、仅绑定到某一天的任务。 |
| **提醒** | Reminder | 在指定时间通知用户处理任务的机制。 |

## 同步

| 术语 | 英文 | 定义 |
|------|------|------|
| **同步引擎** | Sync Engine | 负责检测数据变更、读写云文件、调用 CRDT 合并的模块。 |
| **文件监视器** | File Watcher | 监控云存储目录中文件变更的组件。当其他设备修改了数据文件时触发合并。 |
| **冲突** | Conflict | 多设备同时修改同一数据导致的不一致。CRDT 架构下冲突自动解决，无需用户干预。 |
| **离线优先** | Offline-First | 应用设计原则：所有功能在无网络连接时仍可完整使用，联网后自动同步。 |

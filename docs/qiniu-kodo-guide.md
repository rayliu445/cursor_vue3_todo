# 七牛云 Kodo 同步配置指南

## 概述

TinyDo 支持通过七牛云 Kodo（对象存储）实现跨设备数据同步。
配置只需 3 步，全程 5 分钟。七牛云提供长期免费额度，无需付费。

## 免费额度

| 项目 | 每月免费额度 |
|------|------------|
| 存储空间 | **10GB** |
| PUT/DELETE 写请求 | **10万次** |
| GET 读请求 | **100万次** |
| CDN 回源流量 | **10GB** |
| 上传流量 | **免费** |

> 你的 todo 数据量（几千条约几百 KB）远低于免费额度，可永久免费使用。

## 配置步骤

### 第一步：注册七牛云账号

1. 打开 [七牛云官网](https://www.qiniu.com/)
2. 点击右上角 **免费注册**
3. 按提示完成注册（邮箱 + 手机号验证）

### 第二步：创建存储空间（Bucket）

1. 登录七牛云控制台 → **对象存储 Kodo**
2. 点击 **新建空间**（或创建 Bucket）
3. 填写：
   - **空间名称（Bucket）**：`todo-app-sync`（或你喜欢的名字）
   - **存储区域**：选择离你最近的，推荐 **华东（cn-east-1）**
   - **访问控制**：**私有空间**
4. 点击 **确定**

### 第三步：获取 AccessKey

1. 鼠标悬停在右上角头像上 → **密钥管理**
2. 你会看到 **AccessKey** 和 **SecretKey**
3. 点击 **复制**，保存到安全的地方

> ⚠️ **注意**：SecretKey 创建后只显示一次，如果丢失需要重新生成。

### 第四步：在 App 中配置

1. 打开 TinyDo → **设置** → **同步**
2. 填写以下信息：

   | 字段 | 值 |
   |------|-----|
   | **Bucket 名称** | 第二步创建的名称，如 `todo-app-sync` |
   | **Region（地域）** | 见下方地域映射表 |
   | **AccessKey** | 第三步复制的 AccessKey |
   | **SecretKey** | 第三步复制的 SecretKey |

   **地域映射表（七牛云控制台 → 空间概览可查看）：**

   | 控制台显示 | 代码填写 |
   |-----------|---------|
   | 华东-浙江 | `cn-east-1` |
   | 华东-浙江2 | `cn-east-2` |
   | 华北-河北 | `cn-north-1` |
   | 华南-广东 | `cn-south-1` |
   | 北美-洛杉矶 | `us-north-1` |
   | 亚太-新加坡 | `ap-southeast-1` |

3. 点击 **测试连接**，验证配置是否正确
4. 连接成功后会自动开始同步

## 常见问题

### Q: 真的免费吗？
是的。七牛云官方提供每月 10GB 免费存储 + 10万次写请求 + 100万次读请求的长期免费额度，不是限时活动。

### Q: 超过免费额度后贵不贵？
你的数据量极小，远低于免费额度。即使未来数据增长到 1GB，每月费用也只有约 **0.1 元**。

### Q: 数据安全吗？
- Bucket 设为**私有**，只有你的 AccessKey 才能访问
- 数据传输使用 HTTPS 加密
- AccessKey 可在七牛云控制台随时禁用或删除

### Q: 能和其他人共享数据吗？
目前不支持多账号共享。每个用户使用自己的 Bucket。

### Q: 如果以后想换服务商怎么办？
同步数据就一个文件（`TinyDo/data.automerge`），下载后上传到新服务商即可，迁移成本极低。
